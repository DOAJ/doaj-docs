1. Bulk create reports which article has invalid metadata

Test context
  • role: publisher
  • testdrive: publisher_with_journal
Setup:

Use the publisher_with_journal testdrive to set up for this test at /testdrive/publisher_with_journal. It creates a publisher account with an API key, owning a journal in DOAJ with Print ISSN "1111-1111" and E-ISSN "2222-2222"

If you have run this testdrive before, use the 'teardown' link from that earlier run first, so that no other journal has these ISSNs

Keep the testdrive tab open (closing it removes the test data) and do the test in a separate tab

At the end of the test please use the 'teardown' link provided by the testdrive to remove test assets from the system

ID Action Expected Result  
L.1.1 Download the test resource file "bulk_api_articles_missing_title.json". It contains 3 articles; the second one has no title

Test Resource: https://raw.githubusercontent.com/DOAJ/doaj/feature/4343_no_info_article_api/doajtest/example_files/bulk_api_articles_missing_title.json 		   
L.1.2 Go to the API documentation page

Application Link: http://testdoaj.cottagelabs.com//api/docs 		   
L.1.3 Open "POST /api/bulk/articles" (Bulk article creation (asynchronous)) and click "Try it out". Enter the api_key from the testdrive result, paste the whole contents of the downloaded file into the body, and click "Execute"    
L.1.3.1   The response code is 202
L.1.3.2   The response body contains an "upload_id" and a "status" link
L.1.4 Open the "status" link from the response in a new tab. If the "status" is "pending" or "processing", wait a few seconds and reload until it changes    
L.1.4.1   "status" is "failed"
L.1.4.2   "error" is "Article at index 1: Field 'title' is required but not present at 'bibjson.'" (articles are counted from 0, so index 1 is the second article in the file)
L.1.4.3   There is no "results" section, because the batch was rejected before import
L.1.5 Go to the Table of Contents for the journal

Application Link: http://testdoaj.cottagelabs.com//toc/2222-2222 		   
L.1.5.1   There are no articles whose title starts with "Bulk API test", because no articles are imported when any article in the batch fails
