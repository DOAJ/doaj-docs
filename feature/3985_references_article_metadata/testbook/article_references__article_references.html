2. References are displayed on the article page

Depends On
  • Article References : Article References : Preparation
Test context
  • role: anonymous
ID Action Expected Result  
N.2.1 Open the public article page for the article "References!" as an anonymous user    
N.2.1.1   A "References" section with the heading "References" is shown
N.2.1.2   The 4 references are shown as a numbered list, in the same order as in the uploaded file
N.2.2 Check the first reference, which contains the DOI "10.1234/abc"    
N.2.2.1   The DOI is displayed as a link
N.2.2.2   Clicking the link opens https://doi.org/10.1234/abc in a new tab
N.2.3 Check the second reference, which contains the URL "https://www.doaj.org/"    
N.2.3.1   The URL is displayed as a link
N.2.3.2   Clicking the link opens the URL in a new tab
N.2.4 Check the third reference, which contains no DOI and no URL    
N.2.4.1   The reference is displayed as plain text with no links
N.2.5 Check the fourth reference, which contains the text "markup"    
N.2.5.1   The reference text is displayed exactly as it was supplied: Taylor, C. (2023) A reference with <i>markup</i> in it.
N.2.5.2   No part of the reference is rendered as italics, and no part of the page layout is broken
N.2.6 Open the public article page of an article which has no references (e.g. an article uploaded from "successful.xml")    
N.2.6.1   No "References" heading and no reference list is shown on the page

3. References are available in the public API

Depends On
  • Article References : Article References : Preparation
Test context
  • role: anonymous
ID Action Expected Result  
N.3.1 Request the article from the API, using the article id noted in the Preparation test, by going to /api/articles/{article_id}    
N.3.1.1   The JSON response contains a "bibjson.reference" array with the 4 references, as strings, in the order they were uploaded
N.3.2 Search for the article via the API search endpoint, e.g. /api/search/articles/bibjson.title:%22References!%22    
N.3.2.1   The article in the results contains the same "bibjson.reference" array

4. References are available in OAI-PMH

Depends On
  • Article References : Article References : Preparation
Test context
  • role: anonymous
ID Action Expected Result  
N.4.1 Request the article record in the DOAJ OAI-PMH format, by going to /oai.article?verb=GetRecord&metadataPrefix=oai_doaj&identifier=oai:doaj.org/article:{article_id}    
N.4.1.1   The record contains a "<references>" element with one "<reference>" element per reference, in the order they were uploaded
N.4.1.2   The reference containing markup is correctly escaped in the XML, and the XML is well formed
N.4.2 Request the same record in the Dublin Core format, by going to /oai.article?verb=GetRecord&metadataPrefix=oai_dc&identifier=oai:doaj.org/article:{article_id}    
N.4.2.1   The record is returned successfully (references are not part of the Dublin Core format)

6. References are shown in the article metadata form

Depends On
  • Article References : Article References : Preparation
Test context
  • role: publisher
ID Action Expected Result  
N.6.1 Go to the "Enter Article Metadata" tab in the "Publisher Area"    
N.6.2 Find the "References" field    
N.6.2.1   The field is a multi-line textarea
N.6.2.2   The help text reads: One reference per line
N.6.3 Fill in the required fields for a new article (title, author, Full-Text URL and the journal ISSNs) and enter 3 references in the "References" field, one per line, leaving a blank line between two of them    
N.6.4 Click "Add Article"    
N.6.4.1   At the top of the page you see the confirmation message: Article created/updated
N.6.5 Open the public page of the article you have just created    
N.6.5.1   The 3 references are shown in the "References" section, in the order you entered them
N.6.5.2   The blank line has not created an empty reference
N.6.6 Create another article without entering anything in the "References" field, then open its public page    
N.6.6.1   No "References" section is shown
