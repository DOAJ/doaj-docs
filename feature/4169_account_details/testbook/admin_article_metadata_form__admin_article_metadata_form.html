8. Test Keyboard Navigation and Dropdown Focus Behaviour

Test context
  • role: admin
Setup:

Use a viewport width of at least 1280 pixels so that the full navigation is displayed.

Complete the navigation checks using only the keyboard. Use Tab to move forwards, Shift+Tab to move backwards, Enter to activate a link or button, and Escape to close an open dropdown.

To begin navigating from the start of a page, reload it and do not click anywhere in the page. Press Tab. If focus remains in the browser controls, press F6 on Windows or Control+F6 on macOS until focus moves into the webpage, then press Tab. On some keyboards, the Fn key must be held while pressing F6.
