1. Author with multiple affiliations is displayed once on the article page

Test context
  • role: Anonymous
  • testdrive: multiple_affiliations
Setup:

Open /testdrive/multiple_affiliations in its own tab and keep it open for the whole test - closing or navigating away from it removes the test data. Do all of the steps below in a separate tab.

At the end of the test use the 'FINISH TESTING AND CLEAN UP' link on the testdrive page, unless you are going on to the other tests in this testset

ID Action Expected Result  
BY.1.1 Open the "article_page" link from the testdrive "links" section    
BY.1.1.1   The authors line reads "Ana Author, Ben Author, Cat Author" - each author appears exactly once
BY.1.2 Click the "Affiliations" button under the authors list    
BY.1.2.1   The affiliations section expands
BY.1.2.2   "Ana Author" is listed once, followed by an ORCiD link and then "University of Oxford", "Harvard University" and "MIT", each on its own line, in that order
BY.1.2.3   "Ben Author" is listed once with "Sorbonne University"
BY.1.2.4   "Cat Author" is listed with no affiliation and no ORCiD
BY.1.3 Click the ORCiD link under "Ana Author"    
BY.1.3.1   https://orcid.org/0000-0001-2345-6789 opens in a new tab
BY.1.4 Use a screen reader or the browser's accessibility inspector on the expanded section    
BY.1.4.1   Each author is a term (dt) and each of their affiliations is a separate description (dd) belonging to it

2. Upload DOAJ XML where an author references multiple affiliations

Test context
  • role: Publisher
  • testdrive: multiple_affiliations
Setup:

Open /testdrive/multiple_affiliations in its own tab and keep it open (see the first test in this testset)

Copy the "doaj_xml" value from the testdrive "upload_data" section and save it as a file called multiple_affiliations.xml. It already contains the testdrive journal's ISSNs.

ID Action Expected Result  
BY.2.1 In a separate tab, log in with the testdrive publisher username and password    
BY.2.2 Open the "publisher_xml_upload" link    
BY.2.3 Choose "DOAJ Native XML" as the format, select multiple_affiliations.xml and click "Upload"    
BY.2.3.1   A flash message is shown: "File uploaded and waiting to be processed. Check back here for updates."
BY.2.4 Wait a short time and reload the page    
BY.2.4.1   The upload is shown as "successfully processed" with the note "1 articles imported (1 new, 0 updated)"
BY.2.5 Open the "journal_toc" link and click the article titled "XML Multiple Affiliations ..."    
BY.2.5.1   The authors line reads "Jane Doe, John Smith" - each author appears once
BY.2.6 Click the "Affiliations" button    
BY.2.6.1   "Jane Doe" shows an ORCiD link, then "University of Oxford" and "Harvard University" on separate lines
BY.2.6.2   "John Smith" shows "Harvard University" and "MIT" on separate lines
BY.2.6.3   "Harvard University" is shown under both authors, although it is defined only once in the XML file

3. Create articles with multiple affiliations through the API

Test context
  • role: Publisher
  • testdrive: multiple_affiliations
Setup:

Open /testdrive/multiple_affiliations in its own tab and keep it open (see the first test in this testset)

You need a tool that can send a POST request with a JSON body, eg curl, Postman, or the API docs page /api/docs

ID Action Expected Result  
BY.3.1 Send a POST request to the "api_create_article" link with header "Content-Type: application/json" and the "api_json_affiliations_list" value as the body    
BY.3.1.1   The response status is 201 and the response contains the new article's id
BY.3.2 Open /article/, then click "Affiliations"    
BY.3.2.1   "Api Author" is listed once with "Uni One" and "Uni Two" on separate lines
BY.3.3 Send a GET request to /api/articles/?api_key=    
BY.3.3.1   The author in bibjson.author has an "affiliations" list: ["Uni One", "Uni Two"]
BY.3.3.2   There is no "affiliation" (singular) field
BY.3.4 Send another POST request in the same way, with the "api_json_legacy_affiliation" value as the body. It uses the old single "affiliation" string field.    
BY.3.4.1   The response status is 201 - the old field is still accepted
BY.3.5 Send a GET request for the second article's id    
BY.3.5.1   The author has "affiliations": ["Old Style University"], converted from the old field

4. Enter and edit multiple affiliations in the article metadata form

Test context
  • role: Publisher
  • testdrive: multiple_affiliations
Setup:

Open /testdrive/multiple_affiliations in its own tab and keep it open (see the first test in this testset)

In a separate tab, log in with the testdrive publisher username and password

ID Action Expected Result  
BY.4.1 Open the "publisher_metadata_form" link    
BY.4.1.1   In the Authors section the field is labelled "Affiliations", with help text telling you to separate multiple affiliations with a semicolon (;)
BY.4.2 Enter Article Title "Form Multiple Affiliations", a Full-Text URL such as https://example.com/form-affs, and select the testdrive journal's ISSN    
BY.4.3 For the first author enter Name "Form Author" and Affiliations "University of Oxford ; Harvard University;;MIT"    
BY.4.4 Click "Add Article"    
BY.4.4.1   The message "Article created/updated" is shown
BY.4.5 Open the "journal_toc" link, open the "Form Multiple Affiliations" article and click "Affiliations"    
BY.4.5.1   "Form Author" is listed once with exactly three affiliations: "University of Oxford", "Harvard University" and "MIT" - extra spaces are removed and the empty value between ";;" is ignored

5. Admin edits an article with multiple affiliations

Test context
  • role: Admin
  • testdrive: multiple_affiliations
Setup:

Open /testdrive/multiple_affiliations in its own tab and keep it open (see the first test in this testset)

In a separate tab, log in as an admin

ID Action Expected Result  
BY.5.1 Open /admin/article/    
BY.5.1.1   The first author is "Ana Author" and the Affiliations field shows "University of Oxford; Harvard University; MIT"
BY.5.2 Change the Affiliations to "University of Oxford; MIT" and save the article    
BY.5.2.1   The article saves without error
BY.5.3 Open the "article_page" link and click "Affiliations"    
BY.5.3.1   "Ana Author" now shows only "University of Oxford" and "MIT"
BY.5.3.2   The other authors are unchanged
