1. Create an article with multiple author affiliations via CRUD API

Test context
  • role: Publisher with existing journal and API key
ID Action Expected Result  
B.1.1 Obtain your API key from your publisher user profile page (/account/)    
B.1.2 Prepare an Article JSON payload containing authors with multiple affiliations in the "affiliations" list. For example:
{
"admin": {
"in_doaj": true
},
"bibjson": {
"title": "API Multi-Affiliation Research",
"identifier": [
{"type": "doi", "id": "10.1234/api.multi.affil.01"},
{"type": "pissn", "id": "1111-1111"},
{"type": "eissn", "id": "2222-2222"}
],
"journal": {
"volume": "10",
"number": "2",
"publisher": "Test Publisher",
"title": "Test Journal Title",
"language": ["EN"],
"country": "US"
},
"year": "2024",
"month": "06",
"link": [
{
"type": "fulltext",
"url": "https://example.com/api-article-1",
"content_type": "HTML"
}
],
"author": [
{
"name": "Jane Doe",
"affiliations": ["University of Oxford", "Harvard University"],
"orcid_id": "https://orcid.org/0000-0001-2345-6789"
},
{
"name": "Bob Smith",
"affiliations": ["MIT", "Stanford University", "Cambridge University"],
"orcid_id": "https://orcid.org/0000-0002-3456-7890"
}
]
}
}
    
B.1.3 Send a POST request to /api/articles with query parameter api_key= (or header api_key) and the JSON payload in the request body    
B.1.4 Inspect the HTTP response    
B.1.4.1   HTTP status code is 201 Created
B.1.4.2   Response JSON body contains status "created" and an "id" representing the created article ID
B.1.5 Note the returned article ID    

2. Retrieve an article with multiple author affiliations via CRUD API

Depends On
  • API : CRUD Articles : Create an article with multiple author affiliations via CRUD API
Test context
  • role: Publisher or Public
ID Action Expected Result  
B.2.1 Send a GET request to /api/articles/    
B.2.2 Inspect the HTTP response    
B.2.2.1   HTTP status code is 200 OK
B.2.2.2   Response JSON contains "bibjson.author" array with 2 author objects
B.2.2.3   First author ("Jane Doe") contains "affiliations": ["University of Oxford", "Harvard University"] and "orcid_id": "https://orcid.org/0000-0001-2345-6789"
B.2.2.4   Second author ("Bob Smith") contains "affiliations": ["MIT", "Stanford University", "Cambridge University"] and "orcid_id": "https://orcid.org/0000-0002-3456-7890"

3. Update an article's author affiliations via CRUD API

Depends On
  • API : CRUD Articles : Create an article with multiple author affiliations via CRUD API
Test context
  • role: Publisher with existing journal and API key
ID Action Expected Result  
B.3.1 Retrieve the article JSON via GET /api/articles/    
B.3.2 Modify the authors' affiliations in the JSON body, for example updating Jane Doe's affiliations to ["University of Oxford", "Harvard University", "ETH Zurich"]    
B.3.3 Send a PUT request to /api/articles/?api_key= with the updated JSON payload    
B.3.4 Inspect the HTTP response    
B.3.4.1   {'HTTP status code is 200 OK or 204 No Content (status': 'updated)'}
B.3.5 Send a GET request to /api/articles/    
B.3.5.1   The updated affiliations list ["University of Oxford", "Harvard University", "ETH Zurich"] is returned under the author

4. Create or update article with legacy singular affiliation string (backwards compatibility)

Test context
  • role: Publisher with existing journal and API key
ID Action Expected Result  
B.4.1 Prepare an Article JSON payload using the legacy singular "affiliation" string field in bibjson.author, for example:
{
"admin": {
"in_doaj": true
},
"bibjson": {
"title": "Legacy Affiliation API Test",
"identifier": [
{"type": "doi", "id": "10.1234/api.legacy.affil.01"},
{"type": "pissn", "id": "1111-1111"},
{"type": "eissn", "id": "2222-2222"}
],
"journal": {
"publisher": "Test Publisher",
"title": "Test Journal Title"
},
"year": "2024",
"link": [
{
"type": "fulltext",
"url": "https://example.com/legacy-affil-article"
}
],
"author": [
{
"name": "Legacy Author",
"affiliation": "University of Edinburgh"
}
]
}
}
    
B.4.2 Send a POST request to /api/articles?api_key= with the payload    
B.4.3 Inspect the HTTP response    
B.4.3.1   HTTP status code is 201 Created
B.4.3.2   The article is accepted successfully without errors
B.4.4 Retrieve the created article via GET /api/articles/    
B.4.4.1   HTTP status code is 200 OK
B.4.4.2   Response JSON contains "bibjson.author[0].affiliations": ["University of Edinburgh"]
