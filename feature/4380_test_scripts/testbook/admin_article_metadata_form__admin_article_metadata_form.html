Download Testset

1. Preparation

Test context
  • role: Admin
  • testdrive: admin_article_metadata_form
Setup:

Use the admin_article_metadata_form testdrive to set up for this test at /testdrive/admin_article_metadata_form

This creates a journal (in DOAJ) holding 3 test articles ("Success 100", "Success 200" and "Success 300"), a second journal (not in DOAJ) owned by the same non-admin account, and a third journal (in DOAJ) owned by a different account entirely. All ISSNs, DOIs and fulltext URLs are generated fresh each run - use the values shown in the testdrive result throughout this test, not any specific numbers written here

The testdrive's 'owner' account can be used later for the "log in as publisher" step in "Check button linking to the article's page"

At the end of the test suite, use the 'teardown' link provided by the testdrive to remove the test assets from the system

ID Action Expected Result  
B.1.1 Log in as the 'admin' account supplied by the testdrive    
B.1.1.1   3 articles ("Success 100", "Success 200" and "Success 300") are attached to the "Successful ..." journal

2. Updating data other then DOI and Fulltext URL

Depends On
  • Admin Article Metadata Form : Admin Article Metadata Form : Preparation
Test context
  • role: Admin
ID Action Expected Result  
B.2.1 Go to admin journal and articles search, choose Articles from the "Journals vs Articles" facets at the left    
B.2.1.1   Each article in the search results has "Delete this article | Edit this article" option in the lower right corner
B.2.2 Find "Success 300" article    
B.2.3 Click "Edit this article"    
B.2.3.1   The Admin Metadata Form for "Success 300" article is opened in the new window
B.2.4 Check that the PISSN and EISSN dropdowns offer the "Successful ..." journal's ISSNs (shown in the testdrive result) as options    
B.2.5 Check that the PISSN and EISSN dropdowns do NOT offer the "Not In DOAJ ..." journal's ISSN (shown in the testdrive result) as an option    
B.2.6 Check that the PISSN and EISSN dropdowns do NOT offer the "Other Publisher's Journal ..." journal's ISSN (shown in the testdrive result) as an option, even though that journal is in DOAJ - it belongs to a different account, so it must not appear in this owner's dropdown    
B.2.7 Check the Authors section    
B.2.7.1   There is only one author and no "Remove Author" button
B.2.8 Click "Add Author"    
B.2.8.1   New empty Author Subform appears, each has "Remove Author" option
B.2.9 Click "Remove Author" under one of the authors    
B.2.9.1   The author is removed from the list
B.2.10 Change the title to "Success 400"    
B.2.11 Add an author filling in any string as a name, an affiliation and an orcid id in the correct form, for example https://orcid.org/0001-1234-1234-444X    
B.2.12 Change all the other fields except doi and fulltext URL to something easily recognisable    
B.2.13 Click "Update Article" button    
B.2.13.1   Green banner saying "Article created/updated" is shown at the top of the page.
B.2.14 Search for "Success 400" article again    
B.2.15 Close the page with the Article Metadata Form    
B.2.16 Click "Edit the article"    
B.2.16.1   Confirm all the metadata is updated
