1. Accept a New Application

Test context
  • role: admin
  • testdrive: application_state_change
Setup:

Use the application_state_change testdrive to set up for this test - an admin account, and a Ready-status new application titled 'Application State Change - Accept New Application <run_seed>' owned by a real publisher account. OR provide those yourself.

Important: the testdrive page tears down its data as soon as you navigate away from it. Log in and run the test in a separate browser tab/window, leaving the testdrive tab open until you have finished.

ID Action Expected Result  
J.1.1 Go to the "Applications/Update Requests" page in the Administration area    
J.1.2 Search for the testdrive's "Accept New Application" record (it is in status Ready) and click "Review application"    
J.1.3 Complete any required fields, and then change the Application Status to "Accepted"    
J.1.4 Click "SAVE"    
J.1.4.1   A flash message indicates that a new journal was created, and links to that journal
J.1.4.2   A flash message indicates that the application has been updated-
J.1.4.3   A flash message indicates that the journal has been associated with a new or existing user account
J.1.4.4   A flash message indicates an email has been sent to the account holder to tell them journal was accepted.
J.1.4.5   The Application Status field says "Accepted", and a note at the top of the form says "Please note you cannot edit this application as it has been accepted into the DOAJ."
J.1.5 Click the "Unlock and Close" button    
J.1.6 Go to the mailtrap.io inbox for the test environment you are working in    
J.1.6.1   There should be a suitable email to the journal owner indicating that their journal has been accepted
J.1.6.2   There should be a suitable email to the journal contact indicating that their journal has been accepted

Important: the testdrive page tears down its data as soon as you navigate away from it. Log in and run the test in a separate browser tab/window, leaving the testdrive tab open until you have finished.

ID Action Expected Result
