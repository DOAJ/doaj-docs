Download Testset

1. Upload an XML file which does not meet the Crossref schema

Test context
  • role: publisher
ID Action Expected Result  
N.1.1 Go to the "Upload Article XML" tab in the "Publisher Area"    
N.1.2 Select "Choose file" and select a file from your computer which is XML but not of the Crossref schema. You may use the file "schema_invalid.xml" from the Crossref folder in resources for this test.

Test Resource: https://raw.githubusercontent.com/DOAJ/doaj/feature/4380_test_scripts/doajtest/xml_upload_test_package/Crossref/schema_invalid.xml 		   
N.1.3 Choose "Crossref 4.4.2 XML" from "Format of the file" dropdown    
N.1.4 Click "Upload"    
N.1.4.1   A flash message appears at the top of the screen indicating an error has occurred
N.1.4.2   Your file is shown in the "History of uploads" with status "processing failed" and a suitable entry in the "Notes" (you may need to reload the page). Check that the explanation link goes to a suitable reason and resolution for the problem.

7. Successfully upload a file containing a new article

Test context
  • role: publisher
  • testdrive: article_xml_upload
Setup:

If you have not already, use the article_xml_upload testdrive to set up for this test at /testdrive/article_xml_upload

KNOWN ISSUE: the resource file below (Crossref/4.4.2/successful.xml) does not actually contain ISSN 1111-1111/2222-2222 or the title "Success!" that this test expects - it declares ISSN 2538-4449 and article title "Authors with affiliations" instead. This test cannot pass as written until either the file or these expectations are corrected - flag to the tester/maintainer rather than guessing which side is wrong.

N.7.4 Select "Choose file" and select the test resource file "successful.xml" from the Crossref 4.4.2 test resources folder

Test Resource: https://raw.githubusercontent.com/DOAJ/doaj/feature/4380_test_scripts/doajtest/xml_upload_test_package/Crossref/4.4.2/successful.xml 		   
N.7.5 Click "Upload"    
N.7.5.1   A flash message appears at the top of the screen indicating a successful upload
N.7.5.2   Your file is shown in the "History of uploads" with status "pending"
N.7.6 wait a short amount of time for the job to process, then reload the page (do not re-submit the form data). If the job remains in "pending", reload the page until the status changes.
