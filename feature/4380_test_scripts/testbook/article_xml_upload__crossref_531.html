Article XML Upload: Crossref 5.3.1

Download Testset

1. Upload an XML file which does not meet the Crossref schema

Test context
  • role: publisher
Setup:

You must be logged in using a pure publisher account (no other privileges)

ID Action Expected Result  
O.1.1 Go to the "Upload Article XML" tab in the "Publisher Area"

Application Link: http://testdoaj.cottagelabs.com//publisher/uploadfile 		   
O.1.2 Browse for a file under "Select a file" and select a file from your computer which is XML but not of the Crossref schema. You may use the file "schema_invalid.xml" from the Crossref folder in resources for this test.

Test Resource: https://raw.githubusercontent.com/DOAJ/doaj/feature/4380_test_scripts/doajtest/xml_upload_test_package/Crossref/schema_invalid.xml 		   
O.1.3 Choose "Crossref 5.3.1 XML" from "Format of the file" dropdown    
O.1.4 Click "Upload"    
O.1.4.1   A flash message appears at the top of the screen indicating an error has occurred
O.1.4.2   Your file is shown in the "History of uploads" with status "processing failed" and a suitable entry in the "Notes" (you may need to reload the page). Check that the explanation link goes to a suitable reason and resolution for the problem.

3. Upload a file with duplicates inside the file

Test context
  • role: publisher
  • testdrive: article_xml_upload
Setup:

Use the article_xml_upload testdrive to set up for this test at /testdrive/article_xml_upload

This provides a 'publisher' account owning a journal with print ISSN "1111-1111" and online ISSN "2222-2222" (fixed, to match the hardcoded ISSNs in the XML files used throughout this suite) - not attached to any other journal

This same testdrive setup is reused by several tests in this suite - only run it again (or use its teardown link) if you need to reset to a clean slate

Log in as the 'publisher' account supplied by the testdrive

ID Action Expected Result  
O.3.1 Go to the "Upload Article XML" tab in the "Publisher Area"

Application Link: http://testdoaj.cottagelabs.com//publisher/uploadfile 		   
O.3.2 Browse for a file under "Select a file" and select the test resource file "duplicate_in_file.xml" from the Crossref 5.3.1 resources

Test Resource: https://raw.githubusercontent.com/DOAJ/doaj/feature/4380_test_scripts/doajtest/xml_upload_test_package/Crossref/5.3.1/duplicate_in_file.xml 		   
O.3.3 Choose "Crossref 5.3.1 XML" from "Format of the file" dropdown    
O.3.4 Click "Upload"    
O.3.4.1   A flash message appears at the top of the screen indicating a successful upload
O.3.4.2   Your file is shown in the "History of uploads" with status "pending"
